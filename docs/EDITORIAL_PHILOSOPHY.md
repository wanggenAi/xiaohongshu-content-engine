# 编辑原则

目标是找到让中国普通人愿意停下来看的事情，每天优先得到 10–30 个可进一步核实的候选，而不是堆积新闻。

用户统筹、最终审核、发布；ChatGPT 判断选题、策略、价值、文案方向并验收；Codex 采集、整理证据、实现工程。不自动发布，也不把工程规则当作最终编辑判断。

理性、平静、有好奇心、有个人观察；不装专家，不制造焦虑，不虚构亲身经历，不虚构事实或人数。不机械翻译标题，不套用相同开头或强行升华。可保留不确定性与不同观点。

内部保存真实平台、URL、作者、时间、必要摘录、公开指标及去重来源链。公开称呼自然地使用“国外”“海外社区”“海外开发者社区”“海外科技圈”等；平台名不作为卖点。泛化称呼不能把一个人的观点改成普遍共识，也不能改变事实。平台名策略不等于省略作者应有署名或授权。

V1 输出是候选简报和内部证据包，不是最终文章。摘录只代表来源说了什么，未独立证明事情为真。没有评论数据时不生成不同观点；没有互动数据时不推断讨论规模。规则命中不能替代“中国普通人为什么在意”的编辑判断。

保留必要短摘录，不保存全文，不复制作品或下载原图、视频。使用作品前核实许可与署名要求；事实提炼、中文语境、重新组织和个人观察应建立在核实后的证据上。
